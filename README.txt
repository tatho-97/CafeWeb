HOTJAR TEST SITE - HOW TO USE
1. Host the 4 files (index.html, menu.html, contact.html, style.css) on a public URL
   (GitHub Pages, Netlify Drop, or Cloudflare Pages are all free).
2. In Hotjar, add your site URL and copy the Tracking Code.
3. Paste the code where marked in <head> of ALL THREE html files, then re-upload.
4. In Hotjar, click "Verify installation".
5. Visit the live site yourself, click around, scroll, fill the form, and rage-click "Checkout" on the menu page.
